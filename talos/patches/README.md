# Talos Patching

This directory contains strategic-merge (and JSON6902) Talos config patches that are
layered on top of the base machine config generated by
[talstomize](https://github.com/mirceanton/talstomize). They are referenced by file
path from `talos/talstomize.yaml`.

<https://www.talos.dev/latest/talos-guides/configuration/patching/>

## Patch application order

talstomize layers patches as: **hostname → cluster-wide `patches` → role `controlplanePatches`/`workerPatches` → per-node `patches`**.

## Patch directories

- `global/`: cluster-wide patches, referenced from the top-level `patches:` list
  (applied to every node, both roles). Includes `cluster-network.yaml`, which carries
  the pod/service subnets and `cni: none` that used to be top-level talhelper fields.
- `controller/`: control-plane-only patches, referenced from `controlplanePatches:`.
- `nodes/`: per-node machine config (install disk, kernel modules, network
  bond/VLAN/VIP, node labels/taints) — one file per node, referenced from that node's
  `patches:` list. These carry the fields that were inline node entries in the old
  `talconfig.yaml`.
- `storage/`: per-node volume/disk provisioning (`RawVolumeConfig`, `UserVolumeConfig`,
  `VolumeConfig`), referenced from each node's `patches:` list.

> The per-node system-extension / kernel-arg **schematic** is not a patch — it lives
> under each node's `installer.schematic` in `talstomize.yaml` (or is inherited from the
> cluster-default `installer.schematic`).
